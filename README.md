# SUPER-STORE-SALES-PERFORMANCE-DASHBOARD

## Project Overview

This project is an interactive Excel dashboard created to analyze and visualize Superstore sales performance data. The dashboard helps track business performance, identify profitable areas, monitor losses, and generate actionable insights using data analytics techniques.

The project demonstrates skills in:

* Data Cleaning
* Data Analysis
* KPI Tracking
* Dashboard Design
* Excel Functions & Pivot Tables
* Business Reporting

---

# Objectives

The main objectives of this project are:

* Analyze sales and profit performance
* Identify high-performing categories and regions
* Detect loss-making products or segments
* Monitor profit margins
* Create a visually interactive dashboard for decision-making

---

# Dataset Information

The dataset contains Superstore sales transaction records with fields such as:

* Order ID
* Order Date
* Customer Name
* Segment
* Region
* Category
* Sub-Category
* Product Name
* Sales
* Quantity
* Discount
* Profit

The dataset was cleaned and transformed before creating the dashboard.

---

# Project Structure

The Excel workbook contains the following sheets:

| Sheet Name | Description                                   |
| ---------- | --------------------------------------------- |
| RAW DATA   | Original dataset before cleaning              |
| CLEAN DATA | Processed and cleaned dataset                 |
| KPI CARDS  | KPI calculations and summary metrics          |
| P1 - P6    | Pivot tables and intermediate analysis sheets |
| DASHBOARD  | Final interactive dashboard                   |

---

# Data Cleaning Process

The following cleaning steps were performed:

* Removed inconsistencies and errors
* Formatted date columns
* Extracted Year and Month from Order Date
* Created Profit and Loss columns
* Calculated Profit Margin
* Structured data for pivot analysis
